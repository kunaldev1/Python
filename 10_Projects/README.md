# Python Projects

This directory contains small projects that apply concepts from the learning sections.

## Projects

- [TestProject](TestProject/README.md) — Rock-Paper-Scissors, turtle graphics, a Rich terminal demo, and image background removal.

## How to use this directory

1. Open the README inside a project.
2. Follow its setup instructions and install only that project's dependencies.
3. Run the example and inspect the source code.
4. Read or add tests where appropriate.

Each project should document its purpose, requirements, how to run it, and any limitations. Projects may have separate dependency files because not every project needs the same packages.
